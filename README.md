**Tidewarden — defend the last coral reef.** A 2D canvas tower-defense game: shadow creatures swim the reef channel to bleach the Heart Coral. Build six kinds of bioluminescent towers on reef plots, fight in the glow — Gloom Eels and Murk Jellies can only be hurt in the light — hold 12 waves, then face The Bleach, a three-phase boss. Pearls from kills, upgrades and final forms, generative WebAudio music and sound, particles, screen shake, and a full loop: title, play, pause, boss, victory with stars, defeat, restart.

## Run it

```sh
cd game && python3 -m http.server 8080
# open http://localhost:8080
```

Mouse to build, keys 1–6 pick a tower, Space pauses, Esc deselects, R restarts, M mutes. Add `?shot=title|play|boss|victory&seed=20261116` for deterministic screenshot scenes.
